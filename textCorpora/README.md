# Text Corpora Lab Workspace

This directory contains text corpora used for comparative corpus analysis in DIGIT 100.

## Corpora Included

### corpus1-inaugural
Presidential Inaugural Addresses (1789-2025)
Source: introDH-Hub text collections (https://github.com/newtfire/introDH-Hub/tree/master/textFiles/inaugural)

### corpus2-state-of-the-union
State of the Union Addresses
Source: introDH-Hub text collections (https://github.com/newtfire/introDH-Hub/tree/master/textFiles/state-of-the-union)

## Purpose
These texts are used for n-gram analysis and word frequency comparison using Voyant Tools and AntConc.
Results and analysis are published at: https://dorianbailey.github.io/DBPortfolio/corpus-analysis.html

Note: These files are a "text lab workspace" and do NOT appear on the website directly.
